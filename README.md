# 📊 Superstore Sales Analytics Dashboard

## 📌 Project Overview

This project analyzes Superstore sales data using Python, SQL, Excel, and Power BI to uncover business insights and create an interactive dashboard for decision-making.

The project covers the complete Data Analytics workflow from data cleaning to dashboard development.

## 🔍 Key Business Insights

- Furniture generated the highest sales.
- East region recorded the highest sales.
- October was the best-performing month.
- Canon products generated the highest revenue.
- Top customers contributed significantly to total sales.
- Overall Profit Margin was approximately 56.5%.
